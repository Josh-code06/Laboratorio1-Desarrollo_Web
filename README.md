# Laboratorio 1 - PHP

Repositorio correspondiente al Laboratorio 1 de PHP.

## Descripción

En este laboratorio se desarrollaron diferentes ejercicios utilizando **PHP**, **HTML** y **CSS**.

Los programas permiten realizar operaciones y conversiones básicas mediante datos ingresados por el usuario.

## Ejercicios

* **Problema 1:** Cálculo del área y perímetro de un círculo.
* **Problema 2:** Conversión de pulgadas a centímetros.

## Tecnologías utilizadas

* PHP
* HTML
* CSS
